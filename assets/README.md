# Avatar credit

Tendou Kei is the experimental character/avatar used by this project. The user supplied the fan art; its filename credits **Manic-san**. No original source URL was supplied.

The README uses a square edit/crop of that supplied illustration, displayed at 160 × 160 px. The edit used the built-in imagegen tool with this request: “Perform only a square 1:1 crop, frame Kei's face and glasses, preserve the illustration, add no text or decoration.”

The project code is MIT. The character and artwork retain their respective creators' rights; the code license does not relicense the artwork. This is a fan project, not an official Blue Archive product.
