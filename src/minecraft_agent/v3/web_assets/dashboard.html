Minecraft của bạn

Nhân vật nào là bạn?

Liên kết để Kei nhận ra bạn khi chat trong Minecraft. Cần plugin Kei trên server.

Thêm server từ Panel

Dùng địa chỉ panel bạn thường đăng nhập và Client API key trong phần tài khoản. Key được giữ ở máy chạy bot, không trả lại trình duyệt.

Ai được làm gì?

Quyền chỉ áp dụng cho server đã chọn. Chủ server có thể giao quyền quản lý và thu hồi bất cứ lúc nào.

Thêm hoặc sửa quyền

Bật Developer Mode trong Discord → bấm vào người đó → Copy User ID.

Phạm vi và mức quyền là hai lựa chọn riêng. Full access không tự mở quyền host. Minecraft-only dùng công cụ giới hạn theo server; không phải sandbox hệ điều hành.

Bạn chưa quản lý quyền của server nào. Chủ server có thể cấp quyền cho bạn; mức thân thiết với Kei không thay thế việc đó.
