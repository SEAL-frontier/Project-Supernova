Who is Kei?

Someone to talk to.

Kei is an open-source Discord chatbot and Minecraft assistant. She chats in DMs or public channels, remembers meaningful things, and helps look after servers when granted permission by the owner.

Because servers don't fix their own lag.
And you need someone to listen, too.

You are already on Discord. Ask Kei to check the server, look through logs or handle a task right in the conversation. Everyday chat and server work can live in the same place.

Custom config

Write rules in TOML. Each tool can allow, deny, or auto_review changes. Optional path and command patterns narrow access further.

Show an example
[tools]
"*" = "auto_review"
files = "allow"
power = "deny"

[paths]
allow = ["config/*", "plugins/*"]
deny = ["plugins/private/*"]

[shell]
deny = ["*rm -rf /*"]

These are application rules, not an OS sandbox. A rule cannot grant a server, host identity or capability this person does not already have. Invalid or unsupported rules are rejected.
